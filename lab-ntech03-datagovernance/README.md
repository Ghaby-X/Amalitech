# Data Governance

Labs on data classification, access control, and cross-jurisdiction compliance for a fictional ed-tech/e-commerce operation.

## Files

| File | Purpose |
|---|---|
| `data-access-decision-simulator.md` | EduConnect Ghana scenario: three access-request tickets (marketing data pull, third-party analytics partnership, right-to-be-forgotten deletion). Each is worked through as a Data Access Decision Form covering decision, data lifecycle stage, justification (classification policy, least privilege, Ghana DPA), and action steps. |
| `multi-jurisdiction-compliance-response-matrix.md` | Isoko Marketplace scenario: three customer data-deletion requests spanning Rwanda (Law N°058/2021), the EU (GDPR), and California (CCPA/CPRA). Compares legal rights, exemptions, response deadlines, penalties, and cross-border transfer safeguards across the three regimes. |
